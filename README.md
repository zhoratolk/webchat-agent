# webchat-agent

Use free web chats (GLM, Qwen, Kimi, DeepSeek, Gemini) as agents: a robot drives a real Chrome, types the
question, attaches files, waits until the answer is finished and hands it back as markdown. Works as an
**MCP server** (Claude Code, any tool-calling model, even a local one), a **CLI** and an **OpenAI-compatible API**.

Робот, который превращает бесплатные веб-чаты нейросетей в агентов. Он сам открывает чат в настоящем Chrome,
выбирает самую сильную модель и максимальный уровень размышлений, пишет вопрос, прикладывает картинки и файлы,
ловит конец ответа и возвращает его текстом. Разговор можно продолжать (ссылка на чат сохраняется) или начать
новый чат. Ключей API нет: работает через ваш вход на сайте или гостем, если сайт это позволяет.

## Что умеет

- **Модель и размышления.** Под каждый сайт есть шаги, которые выбирают лучшую доступную модель и максимальный
  режим размышлений (GLM: GLM-5.3 и Effort Max, Qwen: Qwen4-Max и «Мышление», Kimi: K3.1 Pro и «极致»).
  Модели, закрытые для вашего аккаунта, пропускаются. Можно назвать модель явно: `--model GLM-5.2`.
- **Файлы и картинки** уходят через загрузку на сайте. Сообщение длиннее 30 000 символов отправляется файлом `message.md`.
- **Конец ответа.** Пропала кнопка «стоп», и текст не менялся 3 секунды.
- **Ответ в markdown.** Его берёт кнопка «копировать» самого сайта, а если её нет, HTML конвертируется в markdown.
- **Ветки.** `thread` хранит ссылку на чат, следующий вопрос уходит в тот же разговор. `new_chat` начинает заново.
- **Совет.** Один вопрос нескольким чатам параллельно, каждый в своей вкладке.
- **Честные остановки.** Если сайт просит войти, показывает окно возраста или капчу, робот сразу возвращает ошибку
  `login` / `captcha` со скриншотом. Капчи робот **никогда** не решает, их решает человек в окне робота.

## Состояние сайтов

| Сайт | Без входа | Проверено |
|---|---|---|
| GLM, chat.z.ai | только текст и модель Flash; файлы просят войти; после нескольких вопросов бывает капча | 2026-11-13 |
| Qwen, chat.qwen.ai | спрашивает год рождения; файлы только после входа | меню моделей и режимов проверены; ответ ещё нет |
| Kimi, kimi.com | отправка требует входа | меню проверено; ответ ещё нет |
| DeepSeek | только со входом | селекторы по известной вёрстке, не проверены |
| Gemini | только со входом; через некоторые прокси Google показывает проверку | селекторы по известной вёрстке, не проверены |

Вёрстка сайтов меняется. Все селекторы лежат в [`webchat/sites.json`](webchat/sites.json), и чинится всё
правкой JSON, без кода. Локальная правка без форка: блок `sites` в `config.json` (см. ниже).

## Установка

Нужны Python 3.11+ и установленный Google Chrome (Playwright скачивать браузер не будет, используется ваш Chrome).

```bash
git clone https://github.com/zhoratolk/webchat-agent && cd webchat-agent
python -m venv .venv && .venv/bin/pip install -e .        # Windows: .venv\Scripts\pip install -e .
```

`config.json` в корне (необязательно):

```json
{
  "profile": "C:/webchat/chrome-profile",
  "cdp_port": 9341,
  "proxy": "socks5://127.0.0.1:10808",
  "headless": false,
  "sites": {"glm": {"stop": "button[aria-label='Stop']"}}
}
```

Робот запускает **отдельный** Chrome со своим профилем (ваш обычный браузер не трогается) и оставляет окно
открытым. Один раз войдите в нужные сайты в этом окне: `webchat open deepseek`. Вход запоминается в профиле.

## Использование

```bash
webchat ask glm "Разбери таблицу" --file data.csv --thread review
webchat ask glm "А теперь по неделям" --thread review          # тот же разговор
webchat ask glm "Новая тема" --thread review --new             # новый чат
webchat council "Вопрос" --sites glm,qwen,kimi
webchat status kimi                                             # готов ли сайт + скриншот
webchat threads | webchat history review
```

MCP (Claude Code и любые агенты с инструментами):

```bash
claude mcp add --scope user webchat -- /path/to/.venv/bin/webchat-mcp
```

Инструменты: `ask`, `council`, `site_status`, `list_sites`, `list_threads`, `thread_history`.

OpenAI-совместимый API (только на 127.0.0.1, без авторизации, наружу не открывать):

```bash
webchat-api --port 8765
curl http://127.0.0.1:8765/v1/chat/completions -d '{"model":"glm","messages":[{"role":"user","content":"привет"}]}'
```

Без `thread` вся история складывается в один запрос в новом чате. С `"thread": "имя"` (или полем `user`)
отправляется только последнее сообщение в живой разговор.

## Добавить сайт

Новая запись в `sites.json`:

- `home`: адрес нового чата;
- `input`: поле ввода;
- `send`: CSS-селектор кнопки или `enter`;
- `stop`: кнопка остановки, видна во время ответа;
- `message`: сообщение ассистента;
- `answer`: текст ответа внутри сообщения;
- `thinking`: блок размышлений, он вырезается;
- `copy`: кнопка «копировать»;
- `file_input`: поле загрузки файлов;
- `login_wall`: признаки стены входа;
- `model_steps`: шаги выбора модели и уровня размышлений.

Шаги `model_steps`:

- `{"click": css}`: нажать;
- `{"pick": [css, …]}`: нажать первый доступный вариант;
- `{"key": "End", "on": css}`: клавиша на элементе (например, ползунок усилия);
- `{"wait": s}`: пауза.

Любой шаг может быть `"optional": true`.

## Ограничения и честность

- Автоматизация веб-интерфейса может нарушать правила сайтов. Используйте свои аккаунты на свой риск;
  лучше отдельные аккаунты, а не основные.
- У гостей и бесплатных аккаунтов есть лимиты. Робот их **не обходит**: не чистит куки, не меняет личности,
  не решает капчи. Упёрлись в лимит, значит берите другой сайт (`council`) или подождите.
- Ответ быстрее не станет: 10 секунд – несколько минут на вопрос, как в самом чате.
